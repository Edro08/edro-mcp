edro-mcp — Especificación Visual de CLI y Adaptadores (Gate 1)

Mockup interactivo del flujo de terminal ("Preguntar qué uso"), compilación a ~/.mcp/bin/ e inyección multi-cliente.

1. Flujo de Extremo a Extremo (Descubrimiento → Build → Perfiles → Adaptadores) Portable (~/.mcp/bin)

1. Descubrimiento

  • Escanea **/mcp.manifest.json
  • Agnóstico al lenguaje (Go, Python, Node, Binario)
  • Valida esquema de variables env

2. Build Global

  • Compila cada MCP seleccionado
  • Instala en ~/.mcp/bin/<binary>
  • Elimina dependencia de cwd del repo

3. Perfiles Multi-Instancia

  • Lee profiles.json o ~/.mcp/profiles.json
  • Ej.: mysql-local, mysql-staging, postgres-local
  • Protege secretos con {env:VAR_NAME}

4. Inyección Segura (Merge)

  • Crea backup .bak previo
  • Preserva MCPs externos y ajustes previos
  • Escribe JSON, JSONC o TOML según cliente

    "mysql-local": {
      "command": "~/.mcp/bin/mysql-mcp",
      "args": [],

        "DATABASE_HOST": "127.0.0.1",

        "DATABASE_USERNAME": "dev_user",
